About The Project

Developed a Python-based Employee Activity Monitoring System that detects user inactivity through real-time keyboard event tracking. Implemented automated notifications, screenshot and webcam capture, and email-based reporting workflows using OpenCV, PyAutoGUI, Pynput, and SMTP services. Enhanced administrative monitoring through automated evidence collection and reporting.
