Air Writing

Virtual Whiteboard - Draw in Air Using Hand Gestures

Python OpenCV MediaPipe NumPy

Project Overview

Air Writing is a virtual whiteboard that allows you to draw in the air using hand gestures. The system tracks your index finger in real-time using computer vision and machine learning, converting finger movements into digital drawings without any physical contact.

Features

Index Finger Tracking

Draw by moving your index finger in the air

Multi-Gesture Control

Different gestures for writing, moving, and erasing

Color Switching

5 colors: Green, Blue, Red, Yellow, White

Adjustable Brush Size

Small, Medium, Large (5px, 10px, 20px)

Erase Mode

All fingers up to erase with 50px radius

Save & Reset

Save drawings as PNG or reset canvas

Gesture Controls

  • Index Finger Only - Writing/Drawing mode
  • Index + Middle Finger - Move cursor without drawing
  • All Fingers Up - Erase mode (50px circle radius)
  • Fist - Idle mode (no action)

Keyboard Controls

  • C - Change color (5 colors available)
  • B - Change brush size (5px, 10px, 20px)
  • R - Reset/clear canvas
  • S - Save drawing as PNG file
  • ESC - Exit application

Technologies Used

  • Python - Core programming language
  • OpenCV - Real-time video processing and canvas operations
  • MediaPipe - Google's ML framework for hand landmark detection (21 points)
  • NumPy - Array operations and image processing

How to Run

# Install requirements
pip install opencv-python mediapipe numpy

# Run the application
python virtual_whiteboard2.py

Requirements

  • Python 3.7+
  • Webcam
  • OpenCV
  • MediaPipe
  • NumPy
