AI Virtual Mouse

Real-Time Hand Gesture Recognition for Touchless Human-Computer Interaction

MediaPipe OpenCV

Project Overview

An innovative hands-free mouse control system that leverages real-time computer vision and machine learning to track hand gestures, enabling users to control computer cursors without any physical touch. This solution demonstrates expertise in AI, computer vision, and human-computer interaction.

Key Features

Index Finger Tracking

Precise cursor movement across entire screen using index finger detection

Pinch Gesture

Index + thumb pinch triggers left click with natural interaction

Technical Architecture

Core Technologies: MediaPipe (Google's ML framework), OpenCV for real-time video processing, PyAutoGUI for system-level cursor control, and NumPy for mathematical computations.

Camera Input → Frame Processing → Hand Detection → Landmark Mapping → Coordinate Translation → Cursor Movement → Gesture Recognition → Click Events
